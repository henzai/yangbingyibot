# 今回のレビュー依頼（目安3分）

**判断してほしいことは1点です。**
全件の質問意図と必要な取得元・不足理由を記録し、ツール契約を具体化しました。
以下の追加能力を初期契約へ含め、作業B（CSV・ID/状態・snapshot基盤）へ進む方針を承認してください。
アプリの変更・PR merge・有料評価・本番切替は今回実行していません。

## 推奨案

**平均・数値/日付比較・加入年数/誕生日計算を初期版の対象に含めます。**
実際の質問全体を確認すると、一覧/人数だけでは不足するためです。

| 質問例（人工） | 回答の作り方 |
| --- | --- |
| 平均年齢が最も高いチームは？ | 同じ条件集合からコードで平均を計算し、欠損と分母も示す |
| 甲さんと同じ身長の人は？ | 甲さんの値を取得し、同じsnapshotで全件抽出する |
| 加入して今何年目？ | 加入日の根拠と基準日を使う。経過年数と「何年目」を区別する |
| 誕生日まであと何日？ | 精度のある誕生日から計算。閏日等の規則が未確定なら保留する |

根拠が足りない場合は、足りない理由を返します。年別順位の空欄、曖昧な人物候補、復元できない前会話、在籍期間の根拠不足を推測で補いません。
「全項目を教えて」は概要だけに縮めず、全許可列をページ取得します。

## こちらで確認したこと

- 820種類すべての質問を読解し、重複を含む876件へ注釈を反映しました。正解値の人手確定や実測カバレッジとは区別しています。
- 神スプレの表示値に対して人物候補と必要列の値の有無を照合しました。曖昧性・欠損・数式エラーも台帳に残しています。
- 4ツールの引数をJSON Schemaにし、型/演算/欠損/全件性/ページングの契約と人工70ケースを整理しました。
- 未完の正解データ、近似重複/会話の関係、概念検索の品質、本番CSV同値性は後続の検証ゲートとして維持します。

**返答は「この方針で作業Bへ進めて」で十分です。**
対象から外したい能力があれば、その項目だけ教えてください。全876件やschemaの細部をユーザーが読み直す必要はありません。

詳細を確認する場合だけ、[契約v0.2](sheet-search-contract.md) の「質問から必要になった操作」と「集計・派生計算」を参照してください。
